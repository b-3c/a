1. Aim
To write a program to implement Huffman Encoding using a Greedy Strategy.
2. Important Theory
1. Greedy Method:
- Greedy algorithm selects the best option available at each step.
- It makes decisions one by one.
- It does not change previous decisions.
2. Huffman Encoding:
- Huffman Encoding is a lossless data compression technique.
- It reduces the size of data without losing information.
- It assigns shorter codes to frequently occurring characters.
- It assigns longer codes to less frequent characters.
- It uses a Greedy approach.
3. Prefix Rule:

No character's code should be the starting part (prefix) of another character's code. This avoids confusion during decoding.

4. Major Steps:
1. Calculate the frequency of each character.
2. Insert characters into a priority queue.
3. Select two nodes having the lowest frequencies.
4. Combine them into a new node.
5. Repeat until one node remains.
6. Assign 0 to the left edge and 1 to the right edge.
7. Generate codes by traversing the tree.
3. Algorithm
1. Start.
2. Read characters and their frequencies.
3. Create a node for each character.
4. Insert all nodes into a priority queue.
5. Remove two nodes with minimum frequencies.
6. Create a new node with their sum.
7. Insert the new node into the queue.
8. Repeat until only one node remains.
9. Traverse the tree and assign 0 and 1.
10. Print Huffman codes.
11. Stop.
Example Output:
Enter a string: aabbbcccc

Huffman Codes:
a : 10
b : 11
c : 0


Note: Huffman codes can differ when frequencies are tied. The codes above are one valid result.
5. Simple Code Explanation
Understand these important parts:

1. Node class
char ch;
int freq;
Node left, right;


Stores character, its frequency and left/right child nodes.

2. Count frequency
freq.put(ch, freq.getOrDefault(ch, 0) + 1);


Counts how many times each character occurs.

3. Priority Queue
PriorityQueue<Node> pq = new PriorityQueue<>(
    (a, b) -> a.freq - b.freq
);


Stores nodes in increasing order of frequency. The smallest frequency comes first.

4. Select two minimum nodes
Node left = pq.poll();
Node right = pq.poll();


Removes the two nodes having the lowest frequencies.

5. Create parent node
Node parent = new Node('-', left.freq + right.freq);
parent.left = left;
parent.right = right;


Combines both nodes and adds their frequencies.

6. Generate codes
printCodes(root.left, code + "0");
printCodes(root.right, code + "1");


Adds 0 for the left side and 1 for the right side.

7. Main method

Takes input, counts frequencies, builds the Huffman Tree and prints the codes.
6. Time and Space Complexity
Complexity	Value
Time Complexity	O(n log n)
Space Complexity	O(n)

Explanation:
- Time: Priority Queue operations take O(log n), repeated for n characters.
- Space: Huffman Tree and Priority Queue require O(n) memory.
