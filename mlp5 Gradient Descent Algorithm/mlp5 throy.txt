3. Theory in simple words
What is Gradient Descent?

Gradient Descent is an optimization algorithm used to find the minimum value of a function.

In simple words:
- Start from an initial point.
- Calculate the gradient (slope).
- Move in the opposite direction of the gradient.
- Repeat until the minimum point is reached.
Why do we move in the opposite direction?

The gradient tells us the direction of the steepest increase. To decrease the function value, we move in the opposite direction.

Important formula:
\[
x_{\text{new}}=x_{\text{old}}-\alpha f'(x)
\]

Where:
- \(x_{\text{new}}\) = New value of x
- \(x_{\text{old}}\) = Previous value of x
- \(\alpha\) = Learning rate
- \(f'(x)\) = Gradient or derivative
For your function:
\[
y=(x+5)^2
\]

Differentiate:
\[
\frac{dy}{dx}=2(x+5)
\]

This derivative is used as the gradient.
Expected result
- Local minimum approximately: -4.99995
- Minimum value of y approximately: 0
- The algorithm stops when the change in x becomes smaller than the precision or reaches the maximum iteration limit.

8. Important viva questions and answers
Q1. What is Gradient Descent?

Gradient Descent is an optimization algorithm used to find the minimum value of a function.

Q2. What is the main purpose of Gradient Descent?

To minimize the function or reduce its error.

Q3. What is a gradient?

A gradient is the derivative or slope of a function.

Q4. What is the learning rate?

The learning rate controls how big a step the algorithm takes during each iteration.

Q5. What happens if the learning rate is too high?

The algorithm may overshoot the minimum and fail to converge.

Q6. What happens if the learning rate is too low?

The algorithm takes a very long time to reach the minimum.

Q7. What is precision?

Precision is the stopping limit that determines when the algorithm should stop.

Q8. What is an iteration?

One complete repetition of the Gradient Descent update process.

Q9. Why do we use a negative gradient?

Because the gradient points towards the steepest increase, while we want to decrease the function.

Q10. What is a local minimum?

A point where the function value is lower than nearby points.

Q11. What is a global minimum?

The lowest value of the function over its entire domain.

Q12. What is the derivative of \((x+5)^2\)?
\[
2(x+5)
\]

Q13. What is the minimum point of this function?

\(x=-5,\ y=0\).

Q14. Which Python library is used to draw the graph?

Matplotlib.

Q15. What is the role of max_iters?

It limits the maximum number of iterations to prevent an endless loop.
