1. Important theory – Write in your journal
Introduction
Blockchain is a decentralized digital ledger that stores transaction records in blocks. It provides security, transparency and immutability.

There are four main types of blockchain:
1. Public Blockchain
2. Private Blockchain
3. Hybrid Blockchain
4. Consortium Blockchain
2. Types of Blockchain
1. Public Blockchain
A Public Blockchain is an open and decentralized network where anyone can join, view transactions and participate in the network.

Features:
- Anyone can participate.
- No central authority controls the network.
- All participants can verify transactions.
- Provides transparency and decentralization.
Advantages:
1. Trustable: Transactions are verified by network participants.
2. Secure: Data is distributed across many nodes.
3. Anonymous: Users can participate without revealing their real identity.
4. Decentralized: No single authority controls the network.
Disadvantages:
1. Slow transaction processing.
2. High energy consumption in Proof of Work networks.
3. Difficult to control and regulate.
Real-time use cases:
- Cryptocurrency transactions.
- Decentralized finance (DeFi).
- Smart contracts.
- Digital payments.
Examples: Bitcoin, Ethereum.

2. Private Blockchain
A Private Blockchain is a restricted network where only authorized users can participate. It is generally controlled by one organization.

Features:
- Only selected users can access it.
- Works within a closed network.
- Provides privacy and controlled access.
- Suitable for organizations.
Advantages:
1. Speed: Transactions are processed faster.
2. Scalability: Network size can be controlled.
3. Privacy: Confidential information is protected.
4. Performance: Limited participants improve efficiency.
Disadvantages:
1. Security: Limited nodes may increase manipulation risks.
2. Centralization: Controlled by an organization.
3. Limited participation: Few nodes can affect the network.
Real-time use cases:
- Internal company auditing.
- Organization voting.
- Asset management.
- Private business records.
Examples: Hyperledger, Corda.

3. Hybrid Blockchain
A Hybrid Blockchain is a combination of Public and Private Blockchain. Some information is private, while selected information is available publicly.

Features:
- Combines public and private networks.
- Uses permission-based and permissionless systems.
- Access is controlled through smart contracts.
- Organizations can decide which information is public.
Advantages:
1. Ecosystem: Combines the benefits of public and private blockchain.
2. Cost: Transactions can be cheaper due to limited verification.
3. Architecture: Provides customization and security.
4. Operations: Controls which transactions are public.
Disadvantages:
1. Efficiency: Difficult to implement and maintain.
2. Transparency: Organizations may hide some information.
3. Participation: Closed access can reduce network participation.
Real-time use cases:
- Healthcare records.
- Government services.
- Real estate.
- Financial companies.
Examples given in the practical: Ripple network and XRP token.

4. Consortium Blockchain
A Consortium Blockchain is a type of blockchain managed by multiple organizations instead of a single organization. It is also known as Federated Blockchain.

Features:
- Managed by multiple organizations.
- Only selected organizations validate transactions.
- Provides controlled access.
- Suitable for business collaboration.
Advantages:
1. Speed: Limited validators make transaction processing faster.
2. Authority: Multiple organizations participate in management.
3. Privacy: Transaction information is shared among authorized members.
4. Flexibility: Decisions can be taken faster within the group.
Disadvantages:
1. Approval: Members must agree on protocols.
2. Transparency: Organizations may hide information.
3. Vulnerability: Compromised nodes may affect network security.
Real-time use cases:
- Banking and finance.
- Payment processing.
- Supply chain management.
- Food tracking between organizations.
Examples: Tendermint, Multichain.
