1. Aim
To write a program to solve the Fractional Knapsack Problem using the Greedy Method.
2. Important Theory
1. Greedy Method:
- Greedy algorithm selects the best option at each step.
- It makes decisions based on the current best choice.
- It does not change previous decisions.
2. Knapsack Problem:
- A knapsack is a bag with limited weight capacity.
- Each item has a weight and a value (profit).
- The objective is to get maximum profit without exceeding the capacity.
3. Fractional Knapsack:
- Items can be divided into fractions.
- We can take a complete item or a part of an item.
- It is solved using the Greedy Method.
4. Steps of Fractional Knapsack:
1. Calculate the value/weight ratio of each item.
2. Sort items in decreasing order of ratio.
3. Select the item with the highest ratio first.
4. Add the complete item if capacity is available.
5. Otherwise, take the required fraction.
6. Calculate the total profit.
5. Difference between Fractional and 0/1 Knapsack
Fractional Knapsack	0/1 Knapsack
Items can be divided.	Items cannot be divided.
Fractions are allowed.	Only complete items are allowed.
Uses Greedy Method.	Usually uses Dynamic Programming for optimal solutions.
Based on value/weight ratio.	Ratio-based greedy is not always optimal.
Example Input
Enter number of items: 3
Enter weight and value: 10 60
Enter weight and value: 20 100
Enter weight and value: 30 120
Enter knapsack capacity: 50


Output:
Maximum Profit = 240.0


4. Simple Code Explanation
1. Item class
int weight, value;
double ratio;


Stores item weight, value and value/weight ratio.

2. Calculate ratio
ratio = (double) v / w;


Calculates the profit per unit of weight.

3. Sorting
Arrays.sort(items,
    (a, b) -> Double.compare(b.ratio, a.ratio));


Arranges items from highest ratio to lowest ratio.

4. Complete item
if (items[i].weight <= capacity) {
    profit += items[i].value;
    capacity -= items[i].weight;
}


If the item fits, take the complete item and add its value to profit.

5. Fractional item
else {
    profit += items[i].ratio * capacity;
    capacity = 0;
}


If the item does not fit, take only the required fraction and calculate its profit.

6. Main method

Takes input, sorts items, selects items and displays maximum profit.
5. Time and Space Complexity
Complexity	Value
Time Complexity	O(n log n)
Space Complexity	O(n)

Explanation:
- Time: Sorting items takes O(n log n) time.
- Space: We store n items in an array, requiring O(n) space.
