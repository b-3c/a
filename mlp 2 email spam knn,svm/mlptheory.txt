Data preprocessing is the process of cleaning and converting raw data into a suitable format for machine learning.

Why is it required?

2. Binary Classification
Binary classification is a machine learning technique used to classify data into two different categories.

In email spam detection:
- 0 – Normal email (Not Spam).
- 1 – Abnormal email (Spam).
The model studies previous emails and predicts whether a new email is spam or not spam.
3. K-Nearest Neighbors (KNN)
KNN is a supervised machine learning algorithm used for classification.

It classifies a new data point by checking its nearest neighbouring data points.

Working:
1. Select the value of K.
2. Calculate the distance between data points.
3. Find the K nearest neighbours.
4. Select the majority class.
5. Assign that class to the new data point.
Example: If K = 5 and 4 neighbours are Spam while 1 is Not Spam, the email is classified as Spam.
4. Support Vector Machine (SVM)
SVM is a supervised machine learning algorithm used for classification.

It finds the best separating boundary, called a hyperplane, between different classes.

Working:
1. Take the training data.
2. Identify the different classes.
3. Find the best separating hyperplane.
4. Classify new data based on which side of the boundary it falls.
5. Train-Test Split Procedure
The dataset is divided into two parts:
- Training data: Used to train the model.
- Testing data: Used to check model performance.
In this practical, 70% data is used for training and 30% for testing.
6. Feature Scaling
Feature scaling converts numerical values into a common range so that features with larger values do not dominate the learning process.

Here, we use MinMaxScaler, which scales values between 0 and 1.
\[
X_{scaled}=\frac{X-X_{min}}{X_{max}-X_{min}}
\]

Step 7. K-Nearest Neighbors
knn = KNeighborsClassifier(n_neighbors=5)knn.fit(X_train, y_train)y_pred_knn = knn.predict(X_test)



- KNeighborsClassifier() creates a KNN model.
- n_neighbors=5 means the model checks the five nearest neighbours.
- fit() trains the model.
- predict() predicts whether test emails are Spam or Not Spam.
- y_pred_knn stores predicted results.
Example: If 4 out of 5 nearest emails are Spam, the new email is classified as Spam.
Step 8. Check KNN accuracy

- accuracy_score() compares actual and predicted labels.
- classification_report() gives precision, recall, F1-score and support.
Meaning of the report:
Term	Simple meaning
Precision	Out of emails predicted as spam, how many were actually spam?
Recall	Out of actual spam emails, how many did the model identify?
F1-score	Combined measure of precision and recall
Support	Number of actual records in each class

Step 9. Confusion matrix
ConfusionMatrixDisplay.from_predictions(y_test, y_pred_knn)plt.show()



A confusion matrix shows how many predictions were correct and incorrect.










- True Positive (TP): Spam correctly predicted as Spam.
- True Negative (TN): Not Spam correctly predicted as Not Spam.
- False Positive (FP): Not Spam incorrectly predicted as Spam.
- False Negative (FN): Spam incorrectly predicted as Not Spam.
Step 10. Find the best K value
error = []for k in range(1, 34):    model = KNeighborsClassifier(n_neighbors=k)    model.fit(X_train, y_train)    pred = model.predict(X_test)    error.append(np.mean(pred != y_test))



- error=[] creates an empty list.
- range(1,34) tests K values from 1 to 33.
- The model is trained for each K value.
- predict() predicts the test results.
- pred != y_test checks which predictions are incorrect.
- np.mean() calculates the error rate.
- append() stores each error value in the list.
Why? To compare different K values and identify one with a lower error rate.
plt.plot(range(1, 34), error, marker='o')plt.xlabel("K Value")plt.ylabel("Error Rate")plt.title("KNN Error Rate")plt.show()



This graph shows how the KNN error rate changes with different K values.

Why? SVM finds a separating boundary between Spam and Not Spam emails.
