1. Artificial Neural Network (ANN)
An Artificial Neural Network is a machine learning model inspired by the working of the human brain. It consists of interconnected units called neurons or nodes.

These neurons are arranged in layers and learn patterns from the given data.

Three main layers:
1. Input Layer: Receives input data such as age, credit score and balance.
2. Hidden Layer: Performs calculations and learns patterns from the input.
3. Output Layer: Produces the final prediction, such as whether a customer will leave or stay.










2. Keras
Keras is a high-level neural network library used to build and train deep learning models. It provides simple functions to create neural networks.
3. TensorFlow
TensorFlow is an open-source machine learning and deep learning library developed by Google. It is used to perform numerical calculations and train neural networks.
4. Normalization
Normalization is a data preprocessing technique used to convert numerical values into a common range, usually between 0 and 1.

It helps prevent features with larger values from dominating the learning process.

Formula:
\[
X_n=\frac{X-X_{\min}}{X_{\max}-X_{\min}}
\]

5. Standardization
Standardization converts data so that it has a mean of 0 and a standard deviation of 1.
\[
Z=\frac{X-\mu}{\sigma}
\]

Here:
- \(X\) = Original value
- \(\mu\) = Mean
- \(\sigma\) = Standard deviation
6. Confusion Matrix
A confusion matrix is a table used to evaluate the performance of a classification model by comparing actual and predicted values.
Term	Meaning
True Positive (TP)	Customer leaves and model predicts leaves
True Negative (TN)	Customer stays and model predicts stays
False Positive (FP)	Customer stays but model predicts leaves
False Negative (FN)	Customer leaves but model predicts stays

Accuracy formula:
\[
Accuracy=\frac{TP+TN}{TP+TN+FP+FN}
\]

Precision:
\[
Precision=\frac{TP}{TP+FP}
\]

Recall:
\[
Recall=\frac{TP}{TP+FN}
\]

F1-score:
\[
F1=2\times\frac{Precision\times Recall}{Precision+Recall}
\]

import pandas as pdimport matplotlib.pyplot as plt



- pandas: Used to read and manage the dataset.
- matplotlib: Used to display graphs.
from sklearn.model_selection import train_test_split



Divides the dataset into training and testing parts.
from sklearn.preprocessing import StandardScaler



Imports StandardScaler to standardize numerical data.
from sklearn.neural_network import MLPClassifier



Imports the Artificial Neural Network classifier.
- MLP means Multi-Layer Perceptron.
- It is a neural network containing input, hidden and output layers.
from sklearn.metrics import (    accuracy_score, classification_report,    ConfusionMatrixDisplay)



- accuracy_score: Calculates model accuracy.
- classification_report: Displays precision, recall and F1-score.
- ConfusionMatrixDisplay: Displays the confusion matrix.
Step 2. Load the dataset
df = pd.read_csv('/content/Churn_Modelling.csv')



- read_csv() reads the CSV file.
- df stores the dataset in table format.
print(df.shape)print(df.head())print(df.isnull().sum())



- shape: Displays rows and columns.
- head(): Displays the first five records.
- isnull().sum(): Counts missing values in each column.
Expected dataset shape: (10000, 14).
Step 3. Remove unnecessary columns
df = df.drop(['RowNumber', 'CustomerId', 'Surname'], axis=1)



- drop() removes unnecessary columns.
- RowNumber: Just the row number.
- CustomerId: Customer identification number.
- Surname: Customer's family name.
- axis=1: Means columns.
Why? These columns are not useful for predicting whether the customer will leave.
Step 4. Convert categorical data
df = pd.get_dummies(    df, columns=['Geography', 'Gender'], drop_first=True)



Explanation:
- get_dummies() converts text categories into numerical columns.
- Geography contains countries such as France, Germany and Spain.
- Gender contains Male and Female.
- drop_first=True removes one category from each group to avoid unnecessary duplicate information.
For example:
Gender	Gender_Male
Female	0
Male	1

Similarly, Geography becomes numerical columns such as Geography_Germany and Geography_Spain.

Why? Machine learning models need numerical input, so we convert text categories into numbers.
Step 5. Select input and output
X = df.drop('Exited', axis=1)y = df['Exited']



- X contains customer details used for prediction.
- y contains the output column Exited.
- Exited = 0: Customer stays.
- Exited = 1: Customer leaves.
Remember: X = Input, y = Output.
Step 6. Split dataset
X_train, X_test, y_train, y_test = train_test_split(    X, y, test_size=0.30, random_state=0)



- train_test_split() divides the dataset.
- test_size=0.30 means 30% testing and 70% training.
- random_state=0 keeps the split consistent.
For 10,000 records:
- Training data = 7,000.
- Testing data = 3,000.
Step 7. Standardization
sc = StandardScaler()X_train = sc.fit_transform(X_train)X_test = sc.transform(X_test)



- StandardScaler() creates a standardization object.
- fit_transform() calculates the mean and standard deviation from training data and standardizes it.
- transform() applies the same scaling to testing data.
Why? Customer features have different ranges. For example, age may range around 18–90, while salary may be much larger. Standardization puts them on a comparable scale.

Important: We fit the scaler only on training data to avoid information leakage from the test set.
Step 8. Create ANN model
ann = MLPClassifier(    hidden_layer_sizes=(100, 100),    max_iter=100,    activation='relu',    random_state=0)



Explanation:
- MLPClassifier() creates the neural network classification model.
- hidden_layer_sizes=(100, 100) means two hidden layers, each with 100 neurons.
- max_iter=100 means the model can train for up to 100 iterations.
- activation='relu' uses the ReLU activation function.
- random_state=0 makes the model's random initialization reproducible.
What is ReLU?

ReLU is an activation function that helps the neural network learn complex patterns.
\[
ReLU(x)=\max(0,x)
\]

Step 9. Train the model and predict
ann.fit(X_train, y_train)y_pred = ann.predict(X_test)



- fit() trains the neural network using training data.
- predict() predicts whether each test customer will stay or leave.
- y_pred stores the predicted results.
Step 10. Calculate accuracy
print("Accuracy:", accuracy_score(y_test, y_pred))



- accuracy_score() compares actual results with predicted results.
- It calculates how many predictions are correct.
Step 11. Classification report
print(classification_report(y_test, y_pred))



Displays:
- Precision
- Recall
- F1-score
- Support
Step 12. Display confusion matrix
ConfusionMatrixDisplay.from_predictions(y_test, y_pred)plt.show()



- from_predictions() compares actual and predicted values.
- plt.show() displays the confusion matrix.
Why? It helps us understand correct predictions and mistakes made by the model.
