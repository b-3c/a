1. Important theory – Write in your journal
1. Structure
A structure is a user-defined data type in Solidity used to store different types of data under one name.

Example: Student ID, Name and Department can be stored in one structure.
2. Array
An array is a collection of elements of the same data type stored under one variable name.
- It stores multiple values.
- Array elements are accessed using an index.
- push() is used to add elements to a dynamic array.
3. Fallback Function
A fallback function is a special function in Solidity that executes when a function call does not match any existing function or when a transaction is sent with empty data.
- It is declared using fallback().
- It must be external.
- It can be payable to receive Ether.
4. Gas and Transaction Fee
Gas: Gas is the unit used to measure the computational work required to execute operations on Ethereum.

Gas Fee: It is the fee paid for executing a transaction on Ethereum.

Formula:
\[
\text{Transaction Fee}=\text{Gas Used}\times\text{Gas Price}
\]
