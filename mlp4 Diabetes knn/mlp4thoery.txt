What is diabetes prediction?

We use patient medical information to predict whether a patient has diabetes or not.

The dataset contains 8 input features:

Glucose	Glucose level
BloodPressure	Blood pressure
SkinThickness	Skin thickness
Insulin	Insulin level
BMI	Body Mass Index
DiabetesPedigreeFunction	Diabetes-related family history score
Age	Patient's age
Outcome	0 = No diabetes, 1 = Diabetes

What is KNN?

KNN stands for K-Nearest Neighbors. It is a supervised machine learning classification algorithm.

It checks the nearest data points and predicts the class based on majority voting.

Example:

If K = 5 and the nearest patients have:
- 3 patients without diabetes
- 2 patients with diabetes
The model predicts No Diabetes (0) because that is the majority.

What is K?

K represents the number of nearest neighbors considered for prediction.

5. Evaluation metrics
Confusion Matrix

It compares actual results with predicted results.
Example confusion matrix from your assignment
123
True Negative (TN)
Correctly predicted no diabetes

28
False Positive (FP)
Predicted diabetes, actually no diabetes

37
False Negative (FN)
Predicted no diabetes, actually diabetes

43
True Positive (TP)
Correctly predicted diabetes


Matrix layout: [[TN, FP], [FN, TP]]

Accuracy: Percentage of all predictions that are correct.
\[
Accuracy=\frac{TP+TN}{TP+TN+FP+FN}
\]

Error Rate: Percentage of incorrect predictions.
\[
Error\ Rate=1-Accuracy
\]

Precision: Out of all patients predicted as diabetic, how many actually have diabetes?
\[
Precision=\frac{TP}{TP+FP}
\]

Recall: Out of all actual diabetic patients, how many did the model correctly identify?
\[
Recall=\frac{TP}{TP+FN}
\]
