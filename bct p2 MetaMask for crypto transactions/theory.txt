1. Important theory – Write in your journal
1. Introduction to MetaMask
MetaMask is a cryptocurrency wallet used to interact with the Ethereum blockchain.
- It is available as a browser extension and mobile application.
- It allows users to send and receive cryptocurrency.
- It helps users manage ETH and ERC-20 tokens.
- It connects users with decentralized applications (DApps).
- It also supports NFTs.
2. Features of MetaMask
1. Ease of Use:
MetaMask has a simple and user-friendly interface. Users can create a wallet easily without an email address.

2. Security:
MetaMask protects wallet information using passwords and private keys. A 12-word Secret Recovery Phrase helps recover the wallet.

3. Built-in Crypto Support:
It supports Ether (ETH) and Ethereum-based tokens such as ERC-20 tokens.

4. Backup and Restore:
Users can restore their wallets using the Secret Recovery Phrase if they change their browser or device.

5. Community Support:
MetaMask has a large user community and provides support for cryptocurrency users.
3. Types of MetaMask Availability
1. Browser Extension: Available for Chrome, Firefox, Brave and Edge.
2. Mobile Application: Available for Android and iOS devices.
4. Important Terms
- Wallet: A digital tool used to manage cryptocurrency and blockchain accounts.
- Password: Protects access to the wallet on a device.
- Private Key: Secret key used to authorize transactions.
- Seed Phrase: A 12-word recovery phrase used to restore a wallet.
- Wallet Address: Public address used to receive cryptocurrency.
- ERC-20: A standard used for creating tokens on Ethereum.
2. Procedure to create a MetaMask wallet








dummies.com


1. Open Google Chrome browser.
2. Visit the official MetaMask website: https://metamask.io.
3. Download and install the MetaMask extension.
4. Open the MetaMask extension.
5. Click on Create a Wallet.
6. Create a strong password for your wallet.
7. Accept the Terms of Use.
8. Click on Reveal Secret Words.
9. Write down the 12-word Secret Recovery Phrase safely.
10. Verify the Secret Recovery Phrase in the correct order.
11. Click on Confirm.
12. Your MetaMask wallet is successfully created.
13. Click on Account 1 to view and copy your wallet address.
14. Check your wallet balance.

3. Wallet Recovery
If the user changes their browser or device, the wallet can be restored.

Steps:
1. Install MetaMask on the new device.
2. Click on Import an Existing Wallet.
3. Enter the 12-word Secret Recovery Phrase.
4. Create a new password.
5. Complete the process to access the wallet.
Note: Never share your Secret Recovery Phrase or private key with anyone.
