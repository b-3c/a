1. Aim
To design an N-Queens matrix with the first Queen placed and use Backtracking to place the remaining Queens to generate the final N-Queens matrix.
2. Important Theory
1. Backtracking:
- Backtracking is an algorithmic technique used to solve problems step by step.
- It tries one possible solution at a time.
- If a choice is incorrect, it goes back and tries another choice.
- It is generally implemented using recursion.
2. N-Queens Problem:
- Place N Queens on an N × N chessboard.
- No two Queens should attack each other.
- Queens cannot be in the same row, column or diagonal.
- The objective is to find a valid arrangement.
3. Backtracking Steps:
1. Place the first Queen.
2. Move to the next row.
3. Check whether the position is safe.
4. If safe, place the Queen.
5. Move to the next row.
6. If no safe position exists, remove the previous Queen and try another position.
7. Repeat until all Queens are placed.
4. Applications of Backtracking:
- N-Queens Problem.
- Graph Coloring.
- Sum of Subsets.
- Hamiltonian Cycle.

Checks whether a Queen can be safely placed in the given position.

If the selected position does not lead to a solution, removes the Queen and tries another position.

5. Time and Space Complexity
Complexity	Value
Time Complexity	O(N!) (upper-bound)
Space Complexity	O(N²)

Explanation:
- Time: The algorithm tries different Queen positions using backtracking.
- Space: The chessboard requires O(N²) space. Recursion requires O(N) additional space.
