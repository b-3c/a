1. Important theory – Write in your journal
1. Smart Contract
A smart contract is a self-executing digital contract stored on a blockchain. It automatically executes predefined instructions when certain conditions are satisfied.
- It works on the If-Then principle.
- It does not require an intermediary.
- It is secure and transparent.
- Once deployed, its code is difficult to change.
- It is commonly written in Solidity.
2. Solidity
Solidity is a high-level, object-oriented programming language used to develop smart contracts on Ethereum blockchain.

Features:
- Used to create smart contracts.
- Supports functions and variables.
- Supports automatic execution of conditions.
- Used in voting, banking and cryptocurrency applications.
3. Remix IDE
Remix IDE is an online development environment used to write, compile, test and deploy Solidity smart contracts.

Website: https://remix.ethereum.org

Steps to execute a smart contract:
1. Open Remix IDE.
2. Create a new Solidity file with .sol extension.
3. Write the smart contract code.
4. Open the Solidity Compiler.
5. Select the compatible compiler version.
6. Click Compile.
7. Open Deploy and Run Transactions.
8. Select the environment and account.
9. Click Deploy.
10. Execute the required functions.

imple explanation of code
Code	Meaning
pragma solidity ^0.8.20;	Specifies Solidity version.
contract Banking	Creates a banking smart contract.
mapping	Stores user addresses and balances.
create_account()	Creates a new bank account.
deposit()	Adds ETH to the user's balance.
withdraw()	Withdraws ETH from the account.
transfer_amount()	Transfers balance between two registered accounts internally.
send_amount()	Sends actual ETH to another address.
user_balance()	Displays the user's balance.
account_exist()	Checks whether the account exists.
require()	Checks conditions before execution.
msg.sender	Address of the person calling the function.
msg.value	Amount of ETH sent with the transaction.
payable	Allows a function or address to receive ETH.
view	Reads data without modifying blockchain state.

Important difference:
- transfer_amount() changes the balances stored in the contract.
- send_amount() sends actual ETH from the contract to the receiver's address.
